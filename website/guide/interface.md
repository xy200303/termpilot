# 界面导览

窗口就两大块：左侧边栏 + 右侧终端区。这篇说清每块放什么。

## 侧边栏

顶部两个页签：**连接**和**文件**。

### 连接页签

已保存的连接按协议和主机分组：**正向 SSH**、**Telnet**、**串口**、**反向监听**、**本机终端**。组可以折叠，每组标题右侧有自己的 **+**。

连接条目左侧是状态点，右侧可以显示备注。**点一下连接条目就会打开一扇终端**；不想新开时，用右键菜单里的「打开」。

连接条目的右键菜单：

- **复制为 Agent 提示词**：把这条连接的事实整理成一段话，方便发给助手。
- **打开** / **新开一扇终端**
- **备注** / **编辑**
- **删除**

反向监听的右键菜单不同：**开始监听 / 停止监听**、复制这条连接、备注、编辑、删除。

### 文件页签

选中一条已连接的 SSH 会话，这里变成远程文件浏览器：目录按层展开，顶部按钮依次是**打开目录、刷新、新建文件夹、上传**。文件右键有编辑、重命名、下载、删除。

双击文本文件进入内置编辑器，`Ctrl+S` 写回。超过 1.5MB 或检测到二进制（内容里有 NUL）不会进编辑器。

如果上次打开的目录已经不存在，面板会提示「已回到登录目录」并退回。

## 标签栏

终端标签排一行：本机终端、SSH、Telnet、串口、反向 shell 混在一起。标签保持自然宽度，放不下时两端出现箭头；鼠标在标签栏上滚轮会变成横向滚动；切换标签时自动滚进视野。

每个标签的右键菜单：**复制为 Agent 提示词**、**重命名**、**备注**、**重新连接**（断开时出现）、**关闭**。断开连接的标签会标出状态。

## 终端区

xterm.js 6 渲染，WebGL 加速。几件事值得知道：

- **复制 / 中断合一**：有选中文本时 `Ctrl+C` 复制，没选中时发 `SIGINT`。`Ctrl+V` 粘贴。
- 终端里的滚轮是上下滚动；鼠标在标签栏上时才变成横滚。
- 中文输入法组字时窗口内容不会左移（0.7.5 修过的问题）。
- 窗口配色和终端配色是两套，设置页分开选。
- 终端右键菜单有**复制**、**截图**、**粘贴**；截图可以取当前画面、指定行或整段滚动缓冲。

## 设置页

侧边栏底部的齿轮打开设置，分五栏：

- **外观**：应用主题（浅色 / 深色 / 跟随系统）和终端配色，互不影响。
- **MCP 服务**：启用内置 MCP Server（只监听 `127.0.0.1`，请求必须带 Bearer 令牌）、端口（默认 `3927`）、危险操作是否先弹窗确认；「合成算法」开关也在这里——打开后截图按终端缓冲拼图，不滚动正在看的画面，关闭则逐屏拍摄。
- **Agent 接入**：一键把 MCP 配置写进各家 Agent（Claude Code、Kimi Code、Codex、Cursor、WorkBuddy、CodeBuddy）。
- **调用记录**：最近的 MCP 工具调用，失败的会标出来。
- **关于**：当前版本号和手动「检查更新」按钮——这是整个应用唯一主动外联的入口。

## 连接表单

新建 / 编辑连接是同一个对话框，按协议切换字段：

- **SSH**：连接 / 认证 / 跳板 / 高级四个页签。连接页可以粘贴整行 ssh 命令，或从 `~/.ssh/config` 导入一个 `Host`；认证页填用户名、密码或私钥及口令。
- **高级**：连接超时（默认 15 秒）、保活间隔（默认 15 秒）、主机密钥（按默认 / 不核对）、地址族（自动 / IPv4 / IPv6）、压缩、ProxyCommand、**文件通道**（自动 / 复用终端连接 / 总是单独拨号）。
- **Telnet**：主机 + 端口（默认 23）。登录在打开的终端里交互完成。
- **串口**：设备路径、波特率（默认 115200）、数据位、停止位、校验。
