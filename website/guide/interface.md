# 界面导览

窗口就两大块：左侧边栏 + 右侧终端区。这篇说清每块放什么。

## 侧边栏

顶部是品牌头：应用图标、TermPilot 字标和「SSH · Telnet · 串口」副标题，右侧的按钮收起整栏。下面是两个页签：**连接**和**文件**。

### 连接页签

已保存的连接按主机地址分组排列，每组下面挂着该主机的各个账号。分组可以折叠。连接条目的右键菜单里有：打开、编辑、复制、删除、**关闭全部窗口**（这条连接下一旦挂着窗口才出现）、**复制为 Agent 提示词**（把这条连接的事实整理成一段话发给助手）。

底部几个固定分组：**Telnet**、**串口**、**反向监听**、**本机终端**，各有自己的 **+** 按钮。反向监听是本机在 `127.0.0.1` 开一个端口等 shell 连回来——没有公网 IP 的机器主动连你，公网暴露交给 cpolar 这类穿透工具。

### 文件页签

选中一条已连接的正向 SSH 会话，这里变成远程文件浏览器：目录按层展开，顶部按钮依次是打开目录、刷新、新建文件夹、上传。文件右键有下载、改名、删除。双击文本文件进入内置编辑器，`Ctrl+S` 写回。

如果上次打开的目录已经不存在，面板会提示「已回到登录目录」并退回。

## 标签栏

终端标签排一行：本机终端、SSH、反向 shell 混在一起，风格对齐 Windows Terminal——标签保持自然宽度，放不下时两端出现箭头，滚轮悬停横向滚动。当前标签两侧的分隔线自动隐藏。

每个标签的右键：关闭、复制、截图、粘贴。断开连接的标签会标出状态，可以重连同一扇终端。

## 终端区

xterm.js 渲染（WebGL 加速）。几件事值得知道：

- **复制 / 中断合一**：有选中文本时 `Ctrl+C` 复制，没选中时发 `SIGINT`。
- 滚轮在终端里是上下滚动；鼠标在标签栏上时才变成横滚。
- 中文输入法组字时窗口内容不会左移（0.7.5 修过的老毛病）。
- 窗口配色和终端配色是两套，设置页分开选。

## 设置页

侧边栏底部的齿轮打开设置，分五栏：

- **外观**：应用主题（浅色 / 深色 / 跟随系统）和终端配色，互不影响；截图默认逐屏拍摄，打开「合成算法」后按终端缓冲拼图，截正在看的画面时不滚动。
- **MCP 服务**：启用内置 MCP Server（只监听 `127.0.0.1`，请求必须带 Bearer 令牌）、端口、危险操作是否先弹窗确认。
- **Agent 接入**：一键把 MCP 配置写进各家 Agent（Claude Code、Kimi Code、Codex、Cursor、WorkBuddy、CodeBuddy）。
- **调用记录**：最近的 MCP 工具调用，失败的会标出来。
- **关于**：当前版本号和手动「检查更新」按钮——这是整个应用唯一主动外联的入口。

## 连接表单

新建 / 编辑连接是同一个对话框，按协议切换字段：

- **SSH**：连接 / 认证 / 跳板 / 高级四个页签。高级页里有连接超时、保活间隔、主机密钥核对、地址族（IPv4/IPv6）、压缩、ProxyCommand，以及**文件通道**（自动 / 复用终端连接 / 总是单独拨号——一次性授权的跳板机选复用）。
- **Telnet**：主机 + 端口（默认 23）。登录在打开的终端里交互完成。
- **串口**：设备路径、波特率（默认 115200）、数据位、停止位、校验。
