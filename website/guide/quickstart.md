# 快速开始

这篇从安装写到连上第一台机器，每一步说明会看到什么。

## 1. 安装

到[下载页](/download)拿对应平台的安装包装好。安装包未做代码签名，Windows 选「仍要运行」，macOS 右键打开。

## 2. 新建第一条连接

打开 TermPilot，左侧是连接列表。点右上角的 **+**，弹出「新建」对话框：

1. **协议**选 SSH（默认）。Telnet、串口、VNC 和 RDP 也在同一个下拉里。
2. 「连接」页填名称、主机、端口（默认 22）。如果你之前用 ssh 命令连过这台机器，也可以直接**粘贴整行 ssh 命令**，或从顶部的「从 ssh_config 导入」下拉选一个 `Host`，表单自动填好主机、私钥和跳板。
3. 「认证」页填用户名，选密码或私钥。私钥可以点「浏览」选文件，不用手敲路径。
4. 有跳板机在「跳板」页填（对应 `ssh -J`），多跳和 ProxyCommand 在「高级」页。
5. 保存。密码和私钥口令用系统钥匙串加密后存在本机，不会离开这台电脑。

保存后连接出现在左侧列表，按主机地址自动分组。

## 3. 打开终端

双击连接，右侧开出一个终端标签并开始拨号。密码登录第一次会提示输入（如果建连接时没存口令）；私钥登录直接进。看到 shell 提示符就是连上了。

几个顺手的点：

- 标签栏放多了可以用滚轮横滚，两端有箭头按钮。
- 终端里**有选中文本时 `Ctrl+C` 是复制，没选中时是中断**；`Ctrl+V` 粘贴。
- 右键菜单里有复制、粘贴、截图。
- 本机终端和远程终端在同一行标签里，点标签栏末尾的 **+** 开一个本机 PowerShell / bash。

## 4. 打开 VNC / RDP 桌面

协议选 **VNC** 或 **RDP**，主机和端口填好即可。VNC 默认 `5900`，RDP 默认 `3389`。RDP 默认内嵌 IronRDP，也可以在表单里切到 FreeRDP 原生窗口。

- 每个桌面连接只保留一个窗口，重复打开会切回已有标签。
- VNC 和内嵌 RDP 默认与本机双向共享文本剪贴板。
- 标签栏用显示器图标区分 RDP、共享屏幕图标区分 VNC。
- 桌面顶部的仪表按钮显示实时上下行、包速率和累计流量。
- 性能模式可选自动、画质、平衡、流畅。

## 5. 传文件

切到左侧「文件」页签，选中一条已连接的会话，远程目录按层展开：

- 顶部按钮上传本地文件、新建文件夹、刷新。
- 双击文本文件直接在内置编辑器里改，`Ctrl+S` 写回服务器（超过 1.5MB 或二进制文件不会进编辑器）。
- 单个文件超过 512MB 会拒绝——几个 GB 的文件请在远端直接处理。

## 6. 交给 AI 助手（可选）

TermPilot 内置 MCP Server，让 Claude Code、Kimi Code、Codex 等助手操作你登录好的终端或桌面：

1. 设置里「MCP 服务」栏打开开关。
2. 进入「Agent 接入」，点「复制接入指引」，把文本发给助手。指引包含 MCP 地址、Bearer 令牌、各客户端配置路径和 Skill 文件位置。
3. 之后直接说「连上某某服务器，跑一下 xx」或「在 VNC 桌面里打开浏览器」。助手用的是你窗口里已经打开的会话或桌面，全程不需要知道登录密码。

没有 Agent 也能用本机命令行 `termpilot`：`tools` 列工具，`schema` 看参数，`call` 调用。
