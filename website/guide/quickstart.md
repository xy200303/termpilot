# 快速开始

这篇从安装写到连上第一台机器，每一步说明会看到什么。

## 1. 安装

到[下载页](/download)拿对应平台的安装包装好。安装包未做代码签名，Windows 选「仍要运行」，macOS 第一次在访达里右键「打开」。

官方包只有三种：Windows x64、macOS Apple Silicon、Linux x64。

## 2. 新建第一条连接

打开 TermPilot，左侧是连接列表。在「正向 SSH」分组右侧点 **+**，弹出「新建正向 SSH」对话框：

1. **协议**选 SSH（默认）。Telnet 和串口也在同一个下拉里。
2. 「连接」页填名称、主机、端口（默认 22）。如果你之前用 ssh 命令连过这台机器，可以粘贴整行 ssh 命令，或从「从 ssh_config 导入」下拉选一个 `Host`，表单自动填好主机、私钥和跳板。
3. 「认证」页填用户名，选密码或私钥。私钥可以点「浏览」选文件，不用手敲路径。
4. 有跳板机在「跳板」页填（对应 `ssh -J`），多跳和 ProxyCommand 在「高级」页。
5. 保存。密码和私钥口令用系统钥匙串加密后存在本机。

**口令在新建连接时填。** TermPilot 不会在终端里临时向你索要密码；表单留空就连不上。系统钥匙串不可用时，应用会拒绝保存凭据，而不是把口令明文写盘。

保存后连接出现在左侧列表，按主机地址自动分组。

## 3. 打开终端

**点一下连接**（不是双击），右侧开出一个终端标签并开始拨号。看到 shell 提示符就是连上了。

几个顺手的点：

- 同一主机再开一个终端，会复用已经登录的会话，不用重新输密码。
- 标签栏放多了可以用滚轮横滚，两端有箭头按钮。
- 终端里**有选中文本时 `Ctrl+C` 是复制，没选中时是中断**；`Ctrl+V` 粘贴。
- 右键菜单里有复制、粘贴、截图。
- 本机终端和远程终端在同一行标签里，点「本机终端」分组右侧的 **+** 开一个 PowerShell / bash。

## 4. 传文件

切到左侧「文件」页签，选中一条已连接的 SSH 会话，远程目录按层展开：

- 顶部按钮上传本地文件、新建文件夹、刷新。
- 双击文本文件直接在内置编辑器里改，`Ctrl+S` 写回服务器（超过 1.5MB 或二进制文件不会进编辑器）。
- 单个文件超过 512MB 会拒绝——几个 GB 的文件请在远端直接处理。
- 跳板只授权一次转发时，编辑连接 →「高级」→ 文件通道选「复用终端连接」。

Telnet 和串口没有文件通道，文件页签会直接说明这一点。

## 5. 交给 AI 助手（可选）

TermPilot 内置 MCP Server，让 Claude Code、Kimi Code、Codex、Cursor、WorkBuddy、CodeBuddy 操作你登录好的会话：

1. 设置 →「MCP 服务」打开开关，端口默认 `3927`，只监听 `127.0.0.1`。
2. 把 README 里那段安装提示发给助手，它会装好配套 skill 并注册 MCP。
3. 之后直接说「连上某某服务器，跑一下 xx」。助手用的就是你窗口里那条已登录的会话，全程不需要知道密码。

没有 Agent 也能用本机命令行 `termpilot`：`tools` 列工具，`schema` 看参数，`call` 调用。

## 6. 从源码运行

需要 Node.js 22（CI 使用的版本）：

```bash
npm install
npm run dev
```

类型检查和构建：

```bash
npm run typecheck
npm run build
```

会话数据库位于 `%APPDATA%\TermPilot\termpilot.db`。
